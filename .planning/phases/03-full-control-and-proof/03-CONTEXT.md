# Phase 3 — Full Control and Proof

The wallet owner confirms plain-word rules before saving them. Blocking rules run before grants. Remembered access covers the paired agent, kind of information and destination. Purpose is shown on every prompt and recorded on every receipt. Changing purpose alone does not re-ask. A one-time decision is bound to the exact request and preview and permits one use. An ongoing decision still requires separate confirmation for sensitive material.

Hosted model names are encouraged at pairing and optional. For a proxy pairing, the configured endpoint is pinned and the wallet records the model actually present in the final request. An ordinary MCP pairing continues to report the owner's declaration.

Agent proposals and pasted memories become private notes after owner review. The owner can separately make each note eligible for sharing from its editor. An existing grant cannot disclose a newly approved proposal.

The local page uses the founder's iOS type ramp, semantic colors, inset groups, approval alert, notification rows and weekly widget. npm publishing remains a founder decision.
