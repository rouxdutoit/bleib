# bleib · on-device "needs" picker — training material

Research material for training bleib's offline memory picker: the labelled drafts and memories (synthetic, no personal data), the slot taxonomy, the evaluation harness, and the benchmark reports (Runs Q, Q2, Q3, V, X, AF) in `docs/research/local-model*.md`. Start with `docs/research/local-model-af.md`.

Never train on the held-out sets used for evaluation. bleib's product code lives on other branches.
