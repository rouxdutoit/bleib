# Permission justifications

These are the complete permission grants in the production manifests reviewed for bleib 0.1.0. Use them in Chrome’s Privacy practices and in AMO’s Notes for Reviewers. AMO documents the reviewer notes field and the manifest data declaration. [Chrome permission fields](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy/), [AMO submission fields](https://extensionworkshop.com/documentation/publish/submitting-an-add-on/), [Firefox built-in consent](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/).

| Manifest grant | English | Deutsch |
| --- | --- | --- |
| `storage` | Saves the revocable connection credential and per-site quiet-saving settings in this browser profile. Temporarily keeps connection, import and draft targets in session storage so actions stay tied to the right tab. Encrypted memory and receipts live in the desktop app. | Speichert die widerrufbare Verbindung und deine Einstellungen fürs automatische Speichern pro Website in diesem Browserprofil. Verbindungs-, Import- und Entwurfsdaten bleiben vorübergehend in der Browsersitzung, damit Aktionen im richtigen Tab landen. Dein Gedächtnis und deine Belege liegen verschlüsselt in der Desktop-App. |
| `nativeMessaging` | Connects the extension to the installed bleib desktop app on the same computer. Sends candidate statements, draft or preview questions and requested imports for local processing. Gets approval status and the text released for insertion. | Verbindet die Erweiterung mit der bleib-App auf demselben Computer. Die App verarbeitet mögliche Erinnerungen, Entwürfe oder Fragen für die Vorschau und angeforderte Importe. Sie gibt den Status der Freigabe und den freigegebenen Text zurück. |
| `https://chatgpt.com/*` | Reads the ChatGPT editor to save candidate preferences and match the current request. Adds context to a supported draft and reads visible Saved memories or Memory summary entries when you start an import. | Liest das Eingabefeld in ChatGPT, um mögliche Vorlieben zu speichern und zur Anfrage passende Angaben zu finden. Kann einen Entwurf ergänzen und liest beim Import sichtbare Einträge aus den gespeicherten Erinnerungen oder der Zusammenfassung. |
| `https://claude.ai/*` | Reads the Claude editor to save candidate preferences and match the current request. Adds context to a supported draft and reads visible memory entries when you start an import. | Liest das Eingabefeld in Claude, um mögliche Vorlieben zu speichern und zur Anfrage passende Angaben zu finden. Kann einen Entwurf ergänzen und liest beim Import sichtbare Einträge auf der Gedächtnisseite. |
| `https://gemini.google.com/*` | Reads the Gemini editor to save candidate preferences and match the current request. Adds context to a supported draft and reads visible Saved info or instructions when you start an import. | Liest das Eingabefeld in Gemini, um mögliche Vorlieben zu speichern und zur Anfrage passende Angaben zu finden. Kann einen Entwurf ergänzen und liest beim Import sichtbare gespeicherte Infos oder Anweisungen. |
