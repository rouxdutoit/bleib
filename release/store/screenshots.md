# Store screenshot plan

Capture real release builds with synthetic preferences and dedicated demo accounts. Use the final desktop app and signed browser builds. Show public-facing captions in the corresponding locale. Keep account names, addresses, browser profile identifiers and unrelated chats out of frame. Use a consistent browser window and readable text. The desktop app UI in the reviewed build is English. Use German captions with the actual desktop UI in the German set. Verify the final wording of the inserted line against the signed build. No mock controls or implied mobile support.
